# 電腦對手棋力量測紀錄

方法：相鄰難度自我對戰；同一隨機開局雙方各執先後手一次；每盤完整下完（達步數上限才判和）；
AI 使用網站上的實際思考時間；Elo 差 = −400·log10(1/s − 1)，括號為 95% 信賴區間。
區間包含 0 代表「無法確定較高難度比較強」。

重跑：`node tests/strength/elo-ladder.js --games=24`（JS AI）；
引擎難度：以本機 HTTP 伺服器開啟 `tests/strength/engine-ladder.html?games=8`。

## 發現與處理

### 圍棋：改用蒙地卡羅樹搜尋（UCT + RAVE）

量測時發現舊 AI **永遠不虛手**（候選走法中直接濾掉虛手），對局只能靠步數上限結束。

對局現在以雙方虛手、數子結束（平均約 93 手）。

### 五子棋：大師的搜尋深度實驗（大師 vs 困難，各 80 盤）

| 大師設定 | Elo 差 |
|---|---|
| 深度 4 | −191 (−294, −111) |
| **深度 5** | **−17 (−96, +59)** |
| 深度 6 | −108 (−195, −32) |
| 深度 7 | −80 (−163, −4) |
| 深度 8（原設定） | −98 (−184, −22) |
| 深度 7 + 內層候選 20 | −17 (−96, +59) |
| 對稱評估（防守權重 1.0） | −89 (−174, −13) |

結論：搜尋越深反而越弱（前向剪枝 + 戰術評估在深層放大誤差）；調整評估權重無效。
處理：大師深度設為 5（與困難持平，不再倒退）。要讓大師真正變強需要換方法（威脅空間搜尋或 Rapfi 引擎）。

## 待辦

1. 西洋棋／象棋／將棋：簡單、普通改用 Fairy-Stockfish 低強度設定，並用本工具校準。
2. 五子棋：威脅空間搜尋（VCT）或評估 Rapfi WASM。
3. 雙陸棋：困難／大師幾乎沒用到時間預算（每步 1–8 毫秒），需要更好的評估函數（例如 2 層期望值搜尋）。
4. 圍棋：大師 vs 困難差距尚不顯著，可加入模擬策略（提子／逃叫吃）提升。
